## Jak pisać raport

Plik nazywamy `RRRR-MM-DD-raport-temat.md`, na przykład `2026-12-10-raport-test-integracji-a.md`. Raport zawiera:

1. Datę, uczestników i wersję systemu (commit).
2. Środowisko: symulator czy prawdziwe API, z którymi partnerami.
3. Wykonane przypadki z [planu testów](../plan-testow.md) z wynikiem: zaliczony albo niezaliczony.
4. Znalezione błędy z linkami do issue.
5. Wnioski i otwarte problemy, z osobą i terminem rozwiązania.
